Question 1

IfElse_EligibleVoting

Read the age of a person.

- If the age is **18 or greater**, print:

```
Eligible to vote
```

- Otherwise, print:

```
Not Eligible to vote
```

### Input Format

A single integer representing the age of the person.

### Output Format

Print either:

```
Eligible to vote
```

or

```
Not Eligible to vote
```

Example 1:

Input:

```
15
```

Output:

```
Not Eligible to vote
```

Constraints:

```
1 <= age <= 150
```
